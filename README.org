* dotfiles

The git worktree is inspired from [[https://fuller.li/posts/organising-dotfiles-in-a-git-repository/][organizing dotfiles in a git
repository]]. The rest is just years of collecting stuff.

** Initial dotfiles installation
Creates and registers the =~/.ssh/github= key when needed (opens GitHub's SSH keys page),
then checks out the dotfiles and copies =.gitconfig.ref= and =.ssh.config= into place when missing.
Existing files that would be overwritten are moved to =~/.files-backup/=.
 #+begin_src shell
$ curl --fail --silent --show-error --location https://raw.githubusercontent.com/j-martin/dotfiles/main/.setup/bootstrap.sh | bash
 #+end_src

** Setup and configuration
Install applications and other configurations.
 #+begin_src shell
$ .setup/setup.sh
 #+end_src
